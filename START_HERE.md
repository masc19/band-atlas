# START HERE — build an atlas for your band (no code)

You need: a Claude account with web search (claude.ai, the Claude desktop app, Cowork, or Claude Code). Nothing to install, no API key.

**1.** Open a new Claude conversation, set its model to Sonnet (the mid-tier one — bigger models just use your allowance faster here), and attach this whole package (the zip, or the unzipped folder).

**2.** Paste this as your first message:

> Read `prompts/run-in-claude.md` in the attached band-atlas package and follow it exactly, starting with the interview. Ask me one question at a time.

**3.** Answer the questions — Claude offers either to ask them one at a time with options to pick, or to let you fill in `intake/form.html` (open it in your browser, tap through, press *Build profile*, paste the JSON). Pick **quick** the first time (10–15 minutes). You'll get a single HTML file — open it in any browser — and a 30-day plan in the chat.

If you're in **Cowork or Claude Code** with this folder open, you can skip step 2 and just say: *build my band atlas*.

Before the research starts, Claude asks you to switch the chat to Sonnet and tells you how to avoid approving every website one by one (set the permission selector in the message box to *Automatically approve*, and click *Always allow for this website* on the few website prompts that still appear).

Everything else in this package (`atlas/`, `tests/`, `docs/running.md` beyond Path A) is for developers and you can ignore it.
